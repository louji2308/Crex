## 4. Judge-path validation

What a judge (or reviewer) can run today:

```bash
pnpm install                      # requires Node >= 24, pnpm >= 11
pnpm -r typecheck                 # strict TS, 12/12 workspaces green
pnpm -r test                      # 742 tests green (incl. 33/33 benchmarks)
```

Local worker + D1:

```bash
cd apps/worker
npx wrangler d1 migrations apply crex --local
npx wrangler dev                  # or: pnpm --filter @crex/worker dev
```

Live deployment: `https://crex-worker.loujanb2008.workers.dev` (bindings DB, MEDIA,
SOURCE_TO_RELEASE, AI vars) — see runbook §13 for `/health` semantics.

Honest gating: AI/STT routes (`/ai/analyze`, `/ai/understand`, `/evidence-graph/
build`, `/generate`) return `503 AI_NOT_CONFIGURED` when no provider key is set —
they never fabricate output. Without API keys the full judge journey is
exercised by `pnpm -r test` (227 worker tests, including stubbed-end-to-end AI
paths and the judge-path E2E through real HTTP + real D1).
